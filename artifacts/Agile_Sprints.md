# Agile Sprints Plan
## K.A.R.S.H Athlete Coaching

### Sprint 0: Setup and Architecture ✅
- Setup project repository and CI/CD pipelines.
- Establish design system, theme, and component library foundations.
- Define API contracts between Frontend and Backend.
- Setup routing and basic page scaffolding.

### Sprint 1: Authentication and Onboarding ✅
- Implement login, registration, and password reset flows (Google OAuth integrated).
- Role-based routing setup (Coach vs. Athlete dashboards).
- User profile setup and onboarding steps.

### Sprint 2: Core Dashboard and Navigation ✅
- Global navigation (Navbar) and layout construction.
- **Athlete Dashboard:** Summary of the current training sessions and finding new sessions.
- **Coach Dashboard (Professional Portal):** Setting availability and managing slots.

### Sprint 3: Booking & Performance Management ✅
- **Payments:** Razorpay integration for booking slots.
- **Athlete View:** UI to log daily performance (sleep, hydration, etc.).
- **Backend:** AI integration (Gemini) for performance feedback.

### Sprint 4: Communication and Analytics ✅
- Implement data visualization components (Recharts).
- In-app WebSocket Chat for direct communication.
- Learning Hub for educational materials.

### Sprint 5: Testing, Polish and Delivery (Current) 🚧
- Write Unit and E2E Tests (Currently 0 tests exist for both Backend and Frontend).
- Comprehensive UI/UX polish and Responsive Design Audit.
- Accessibility audits and performance optimization.
- Implement Push Notifications.
- Final QA and bug bashing before release.
